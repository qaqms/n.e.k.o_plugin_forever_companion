## 更新内容

- Agent 模型每日调用上限的默认值由 20 调整为 **100**，仍可在面板设为 5～150 次。
- 「我的日记生成」默认使用 **Agent**，个人日记也复用这条成文模型通道。
- 新增一次性升级迁移：首次成功迁移时，将已保存的成文模型统一设为 Agent、Agent 每日调用上限统一设为 100，**包括此前手动选择的值**。
- 迁移完成后，用户仍可自行修改；后续启动、切换角色或恢复备份不会重复覆盖。存储不可用或迁移读写失败时，延后重试。
- 每日用量继续按插件设置的时区（默认跟随系统）跨日从零计算，无须重启；同日重启保留已用次数。补充预算耗尽后次日恢复自动碎片、个人日记与我的日记生成的回归验证。
- 配置示例、前端缺省值、八语说明与文档同步。

## 升级说明

本次会一次性覆盖上述两项配置，其余设置、日记、归档、统计与壁纸保留。
Agent 用量按角色计数；插件的本地预算与宿主服务端额度分别管理。

导入附件 `forever_companion.neko-plugin` 后，在插件页执行「停止 → 启动」。
首次迁移后可在「情绪 → 模型通道」确认 Agent 与 100 次；之后修改并保存的值会继续保留。
需要留存升级前的配置时，可先在「设置 → 数据管理 → 备份与恢复」导出 `.fc-backup`。

本次仅更新插件，无需修改宿主。
