## 更新内容

- 新增碎片判重与取代：记事前参考已有片段，重复内容不再新增；更新了旧信息时，旧片段保留正文并显示「已被更新」，退出后续检索，仍可在时光日记中翻阅。
- 新增角色可调用的记忆自检工具，一次检查 20 条、最多 30 条现行片段，只返回整理建议，不自动合并、删除或改写记录；30 分钟内至多调用一次。
- 碎片每天的分析次数上限接入实际请求门控，可直接在「设置 → 日记」调整；设为 0 时当天不再分析。
- 修复语气感知与自动碎片共用轮次水位的问题，两者同时开启时也能正常捕获碎片。
- 修复记忆自检与自动碎片共用失败熔断的问题，自检失败不会关闭自动碎片捕获。
- 被取代片段的状态及新增设置同步八种语言。

本版包含已合并的 PR #10 及审查修复。开发阶段的 1.5.0、1.5.1 未正式发行，统一归入 1.4.3，接续正式版本 1.4.2。

## 旧数据兼容

正常升级不迁移、不清空、不自动注入已有数据。旧片段缺少状态字段时继续按现行片段读取，原有日记、归档、统计、设置与壁纸保留。

记忆自检只给建议，不自动修改记录。碎片判重与取代由模型判断，被取代的旧记录保留正文供用户核对。

本次仅更新插件，无需修改宿主。

## 安装

导入附件 `forever_companion.neko-plugin` 后，在插件页执行「停止 → 启动」。需要留存数据时，可先在「设置 → 数据管理 → 备份与恢复」导出 `.fc-backup`。

## 验证

合并前 GitHub CI、Ruff、Hosted TSX 类型与链接、界面检查及导入包严格校验通过。本地回归 1096 项通过、39 项按既有条件跳过；另外 6 项 SaveBar 测试在 LF 格式源码下全部通过，确认此前 Windows 换行格式引起的匹配失败与本次功能改动无关。

正式附件由仓库发行工作流从 `v1.4.3` 标签重新构建，并附带官方 Market 校验报告和 `market-evidence.json`。
