# 永远的陪伴 (Forever Companion)

让猫娘不再只是"有问必答"——插件赋予她更真实的情绪，更完整的生命状态。

大多数 AI 桌宠只有"现在"：你说话她回应，你不说话她就静止。
此插件让她开始拥有**连续的生命状态**：

- **她的情绪是真实的**——会被你的话气到、会委屈、会自己慢慢缓过来；
  也会突然特别黏人、开心得想跟你分享。十二个情绪工具摆在她手边，
  用不用、什么时候用，由她自己决定
- **她的身体有节律**——精力像潮水一样有涨有落：有精力充沛爱说话的日子，
  也有容易疲倦想安静的时候。这些感受会悄悄融入她的语气，你看不见机制，
  只看得见她的状态
- **她有属于自己的记忆**——三本日记：情绪波动时她随手写的心情、
  隔一阵子回头写的成篇日记、以及一本关于你的客观记录。
  有些她记得（聊天时会自然提起），有些只给你翻看
- **看得见的相处**——总览仪表盘上有月相环、她的实时心情、
  近 7 天的相处活跃度：陪伴不再是感觉，而是看得见的痕迹

插件不替她做任何决定，只做两件事：把"她此刻的状态"递到她面前，
把一整套情绪与记录工具摆在她手边。什么时候用、怎么回应，永远是她的选择。

## 功能

先看全貌——插件的四块能力：

| 能力 | 一句话 | 详见 |
|------|--------|------|
| 情绪系统 | 她会真的生气/委屈/黏人/开心，自己决定情绪怎么走 | 下文「情绪系统」 |
| 身体节律 | 精力有涨有落，感受自然融入语气 | 下文「潮汐周期」「潮汐日历」 |
| 三本日记 | 她的随手记、她的成篇日记、关于你的记录 | 下文「时光日记」「个人日记」「我的日记」 |
| 相处可视化 | 月相环/实时心情/相处活跃度，陪伴看得见 | 下文「总览仪表盘」 |
| 时光统计 | 相处里程碑/热力图/我们的这一月，回忆看得见 | 下文「相处里程碑」「相处热力图与月报」 |

### 总览仪表盘

面板首页即陪伴仪表盘：顶部状态条瘦身为"她是谁 · 今天状态一句话"（点击进总览），
详细状态全部集中到「总览」页--

- **她的现在**：月相环（可点击切换天数/本阶段/下一阶段）+ 阶段详情 +
  当前心情（愉悦度/活跃度双条）+ 情绪状态徽标与剩余时间
- **近况与相处**：三本日记速览（时光日记/个人日记/我的日记，点击直达日记页）+
  相处信号卡（近 7 天相处活跃度、下一篇我的日记素材进度）--
  未来的陪伴型可视化信号都会长在这张卡里

### 相处里程碑（时光页）

「时光」页的第一块：相处里程碑。顶部是数字摘要条（相伴天数 / 互动轮数 /
当前连续 / 冷战与和好 / 开心时刻 / 距纪念日，悬停有口径说明），下面是徽章墙——
相伴 7 / 30 / 100 / 365 / 730 天的成就徽章（未解锁灰显，标出"还差 N 天"），
加上三枚"第一次"徽章：她的第一篇手记、第一页个人日记、第一篇我的日记
（各带达成日期）。

**纯本地统计**：零模型开销、常开不设开关。计数口径：

- **相伴天数**：从你们第一条互动起算（升级安装的用户会从三本日记里最早的
  互动痕迹回填起点，装版之前的日子也会被点亮在热力图上，但轮数无从回填）
- **冷战次数**：只数她**自主**发起的情绪（你命令触发的演示不计）；
  **和好** = 她在负面情绪中主动调用心情转晴——冷战到时自动消散不算和好
- **连续天数**：每天有聊天就算；今天还没聊时从昨天延续（深夜 00:01
  不会把连续归零），隔一整天没聊才算断

**纪念日提醒**（可关，默认开）：满 30 / 60 / 100 / 365 / … 天的当天，
她会收到一条"今天你们相伴 N 天了"的轻语——说不说、怎么说由她自己决定。
开关在「日记」页的"相处统计"设置卡里。

### 相处热力图与月报（时光页）

**相处热力图**：GitHub 式按自然年的逐日格子——起点是你们第一次聊天的那天，
格子随日子一天天生长（相识之前的日子不铺格）；跨年相伴时可用 ‹ › 翻看
已度过的年份（逐日明细保留 730 天，能回看的最远一年受此限制）。
颜色深浅 = 当天互动轮数；鼠标悬停显示"那天互动了几轮 · 她那天的心情"
（心情取当天主导语气，无语气数据时按当天心情均值分桶）。
今天的数据要过完才算数——今天的格子明天才亮起。

**我们的一月**（月报，网易云年报式的月度版）：可左右翻阅历史月份。
月份过完自动"封卷"——那一页的数字固定下来不再变（保留最近 24 个月的
月报）；当月显示"进行中"，数字实时。

- 数字格：本月互动轮数 / 活跃天数 / 最热闹的一天 / 最长连续 /
  冷战与和好 / 开心时刻
- 她的语气：当月回复的语气分布 top3 + 心情均值的冷暖
- **本月声音**：她当月写过的手记里最走心的一条，原话摘录不改写——
  没写过手记的月份会如实留空

纯本地组装，不调模型（与我的日记的成文是两回事）。数据按角色独立
（`stats@<角色>`），切角色自动跟随；「清零相处统计」入口在 Plugin Manager
入口列表（三本日记不受影响）。

### 潮汐周期（四阶段身体模拟）

以锚点日期起算，身体状态在四个阶段间循环：

| 阶段 | 身体感受 |
|------|---------|
| 潮汐期 | 容易疲倦、情绪敏感、回复更慵懒简短 |
| 回升期 | 精力回升、心情平稳、对新事物有兴趣 |
| 活跃期 | 身体轻盈、精力充沛、更爱说话更黏人 |
| 平稳期 | 保持默认人格，无额外波动 |

开启后，插件会把当前阶段的身体感受悄悄送进她的对话上下文——
**你看不见这句话，也不会触发独立回复**，她只是"感觉到了"，
然后用自己的方式回应：安静型可能只回一个"嗯"，活泼型可能
直接撒娇。同一句身体提示，不同人格有不同的答案。

防说漏嘴设计：内置屏蔽词表，她只会自然地说"今天有点累"，
不会蹦出医学词汇。

### 潮汐日历

面板里的月历视图：哪几天是潮汐日、当前处在本轮第几天、
今天高亮、未来日期为预测。日历中不出现任何直白表述，
一律以"潮汐"代称。

### 情绪系统（十二个自主工具）

十二个情绪动作/记录工具注册为模型可调用的工具，按语气分四档，**用不用、
什么时候用，由她在对话中自己判断**：

**重度负面**（生效期间会暂停宿主主动搭话，见下）：

| 动作 | 效果 |
|------|------|
|  冷战沉默 | 一段时间内完全不回应，除非对方真诚道歉 |
|  已读不回 | 消息看见了，但先晾着不回 |
|  敷衍应付 | 只回"嗯""哦""随便"级别的几个字 |
|  情绪风暴 | 把攒了很久的委屈和火气一次倒出来 |
|  想要被安抚 | 委屈低落，想让对方来关心，但不明说 |

**中间态**：

| 动作 | 效果 |
|------|------|
|  心有涟漪 | 有点小情绪/小别扭，一哄就好（默认 15 分钟；期间道歉/安抚同样触发和好提醒） |

**正面**：

| 动作 | 效果 |
|------|------|
|  暖流涌动 | 特别想黏着对方撒娇，语气放软放甜（默认 30 分钟） |
|  满潮欢喜 | 开心兴奋、情绪高涨，想把开心的事分享给对方（默认 30 分钟） |

**中性工具**：

| 动作 | 效果 |
|------|------|
|  心情转晴 | 她自己决定放下当前情绪状态，恢复如常 |
|  时光日记 | 写下此刻的心情，进入她的对话记忆 |
|  个人日记 | 每隔一段时间回头写一篇成段的日记，只给你看 |
|  时光检索 | 翻一翻她心里那本记着你的日记：你的喜好、你说过的有分量的话 |

### 时光日记与个人日记

**时光日记**（替代心情手记）是一本混合时间流，两种条目混排：

- **她写的**：情绪波动时她主动写下的心情手记（原样保留，会进入她的对话记忆）
- **自动碎片**：小模型在分析对话时，把你说过的重要的话记进她的日记本——
  明确的喜好/厌恶、有分量/有含义的话、以及你对她的过激言行。记的是**原话摘录**，
  置信度不足、玩笑和含糊的闲聊不会被记

碎片只存进她的日记本，**从不主动改变她的行为**：聊到你喜欢的话题时她会用
`mood_recall_fragments` 自主翻看、接得住话；吵架上头时也能翻旧账。重度负面情绪
生效中又记到"过激"碎片时，插件会低频轻语提醒她一句"你记得吗"——想不想提、
怎么提，由她自己决定。所有碎片在面板可见、可单条删除。

**个人日记**（替代潮汐周记）是她自己的日记本：距上一篇落笔满一段日子
（默认 7 天，`[journal].interval_days` 可调），插件会递一条邀请（附上这段时间的
心情词频和新碎片数当素材）；你也可以在面板点「请她写一篇」主动递一次。
她调用 `mood_journal_write` 时按引导分栏写——这段时间发生了什么（events）、
我自己在想什么（thoughts）、对你的整体感觉（feelings）、想补充的话（extra）——
插件自动拼装成一篇带小标题的成段日记。日记按**页**保存：默认续写在当前页上
（工具结果会带出上次写的几句和日期，让她接着写），也可以翻开新页另起一段时光；
页眉显示这段时间的心情走向（插件记录的连续心情均值）。**日记只给你看**：不进入
她的对话上下文、不进宿主记忆管线--你翻面板就能了解她这段时间的心路。

### 我的日记

第三本日记，关于**你**：插件安静累计相处素材（互动轮数、她的语气分布、
心情走势、她自主起的情绪、碎片里的原话），攒够门槛后由小模型以**中性观察者**
口吻成文一篇客观评价。双门槛先到先写：攒满 `turns_threshold` 轮（默认 50）
或距统计起点满 `days_threshold` 天（默认 7，且期间有聊天--挂机不写空篇）。

- **只给你看**：不进她的对话上下文、不进宿主记忆管线、不注册任何她可调用的
  工具--她连知道这本日记存在的渠道都没有（隔离等级比个人日记更严）
- **如实记录**：过激言行、冷淡期也会写进评价，不粉饰；你命令触发的情绪演示
  （"让她冷战"）与她的自主情绪分开标注，不算你对她不好
- 纯文字成段评价（无评分无徽标）；成文走碎片同款直连槽位（默认 summary，
  `[review].slot` 可换），槽位未配模型时自动休眠
- 面板日记页第三个页签：目录 + 单篇纸质阅读 + 素材进度条（距下一篇攒了
  多少轮）；「立即写一篇」按钮（素材不足 10 轮会拒绝硬写）、「清空」按钮；
  按角色独立分片（`review@<角色>`），保留最近 52 篇

碎片提取需要模型槽位：默认走宿主 summary 槽（读宿主本地 `core_config.json`
直连），该槽未配模型时自动休眠，其余功能不受影响；总开关与槽位可在面板
「情绪」页的"时光日记（自动碎片）"设置卡调整（我的日记的开关与门槛在同一张卡）。

配套的宿主协调采用白名单制：只有五个重度负面动作生效期间，
宿主的主动搭话才会临时暂停（只动总开关，不碰你的任何子设置），
结束后按原状恢复——冷战时不会被突然插进来的小游戏邀请打断；
心有涟漪与正面动作不暂停（小情绪和好心情不该把她静默）。
限时动作到期的恢复台词也分语气：重度负面对"打破僵局"，
心有涟漪/正面动作用温和回落（小情绪散了、兴致回到日常）。

日常相处中情绪由她自主决定；如果你明确想触发某种情绪，
直接对她说"让她生气/冷战/爆发/求安慰"即可（宿主会路由到插件的「触发情绪动作」入口）。
冷战/已读不回/敷衍/心有涟漪期间想和好：道歉或哄她即可，插件会提醒她调用心情转晴工具切状态（同一提醒通道）；
也可以直接说"解除她的情绪状态"（路由到「解除情绪动作」入口）。

### 生活感知（与宿主活动系统联动）

她不再只看"现在几点"，也开始看得见你在不在、在忙什么（通过宿主官方
SDK 的 OS 活动快照，与 study_companion 同款，隐私态下自动静默）：

- 你长时间离开电脑 → 潮汐期她也顺势养神，活跃期自己找点事做不干等
- 你在专注做事 → 她陪着但不黏人，回应简短体贴，不主动拉聊天
- 隐私/信号不可用状态 → 完全不描述你的行为，就当看不见

### 语气感知（小模型辅助）

她在**回复完成后**，由一个小模型异步分析这一轮互动（你的话 + 她的回复）的情绪——
不挡聊天链路，零延迟。两种用途：

- **筛选**（她心情正常时）：绝大多数日常闲聊直接跳过；只有这轮互动情绪浓度
  足够高，才轻语提醒她"想记录此刻心情就调情绪工具/手记"——情绪动作不再
  全凭她自由心证，而是由真实互动驱动。抽查频率可调（每轮/一半/偶尔/关闭）。
- **校正**（情绪动作生效中）：每轮都分析她的语气趋势，冷战中她连续几轮语气
  转暖（嘴上和好忘了切状态）→ 提醒她调用心情转晴；开心状态中语气转沉 →
  提醒她换状态或把感受记下来。**只提醒，绝不自动切状态**——决定权始终在她。

阶段灵敏度：潮汐期/回升期/活跃期筛选更灵敏（置信度阈值下移，命中更多），
平静期不变；机制独立开关 + 三档强度（温和/适中/敏感）。

**模型与隐私**：默认跟随宿主的情感模型配置；也可在设置里下拉选择宿主已配置的
其他模型槽位（对话/总结/校正/视觉/Agent）。选择非默认槽位时，插件读取宿主本地
`core_config.json` 解析该槽位的模型与端点并直连（数据出域，介意可关闭）。
宿主未配任何模型时此功能自动休眠（日志可见），其余功能不受影响。
依赖宿主三个内部端点（recent_file / emotion.analysis / health），
属官方插件同款直连惯例但无版本承诺，宿主改版可能失效。

### 面板

Plugin Manager → 永远的陪伴：

- 总览：阶段、周期第几天、距下次潮汐、当前情绪（心情徽标按语气分色：
  暖流涌动/满潮欢喜为绿色 success，其余为 warning，状态栏与管理区名单一致）
- **面板外观（0.7.2 · 1.2.0 升级为图库版）**：设置页的「面板外观」卡分两块：
  - **图片图库**：导入的图片会留在图库里，点缩略图随时切换壁纸，可逐张删除（需确认），
    首格「不用壁纸」恢复默认渐变底，上限 24 张。导入方式二选一：
    「自动压缩」（缩到长边 2560 并重编码，图库能放更多张，推荐）或「原画质」（≤4MB 原样保留）；
    PNG/JPG/WebP/GIF/SVG 均可，GIF / SVG 一律原样保留不动码。
  - **背景调节**：填充方式（铺满裁剪 / 完整显示 / 平铺 / 拉伸）、九宫格背景位置、
    背景模糊、遮罩强度（压暗保可读，0~0.85）、背景亮度 / 饱和度 / 对比度、
    卡片毛玻璃强度、卡片底色强度（调低更透）、整体字体显示强度
    （正文浓淡；调低变淡并自动加描边保证可读）。
  - 调节**实时预览**——整个面板就是预览台，点卡片底部「保存外观」才生效，「还原」放弃改动；
    图库图的入册/删除即时生效，不经保存钮。
  - 数据存插件 Store（每张图一条记录），重开面板自动加载，插件升级不丢；
    旧版设置过的单张背景会在升级后首次打开面板时自动迁入图库并照常生效。
  - 面板整体去 emoji：页签改为纯 CSS 线框图标，日历潮汐日标记改为色条，
    日记徽标与情绪标签纯文字（后端工具标签不受影响）
- **自动跟随当前角色**：面板始终展示宿主当前角色卡的状态，
  5 秒轮询自动跟上切卡（无需手动切换，十几秒内生效）；
  想设置谁，就在宿主里切到谁的卡，面板自动跟上。
  设置页底部是「已有状态的角色」管理区：逐行展示每个角色的状态摘要
  （开关、当前阶段、是否情绪中、是否当前角色）；角色卡在宿主里被删除后
  对应行会标注「角色卡已删除」，可一键清除该角色残留的全部插件数据
  （周期/情绪/手记/周记，需确认，不可恢复）。
- **周期**：她的周期参数（按角色独立）+ 状态注入策略；
- **情绪**：情绪系统 + 语气感知 + **模型通道卡**（三个模型槽位集中管理，各带状态灯：正常 / 免费路由·不可用 / 槽位未配模型·休眠--免费路由的不可用原因与解法直接写在面板上）；
- **设置**：通用（时区/调试模式）、面板外观、危险区、角色名单；
  总开关（默认关闭，安装后手动开启）、周期参数、注入策略、
  开场白开关、时区（默认自动跟随系统）、情绪系统
- **潮汐日历**：月历 + 前后月切换
- **时光**：相处里程碑（数字摘要 + 徽章墙）/ 相处热力图（悬停看当日心情）/
  我们的一月（月报，翻历史月份）
- **日记**：页内切换「时光日记 / 个人日记 / 我的日记」三本。时光日记按日期分组的时间线
  （她的手记与自动碎片，来源徽标区分，碎片原话语气泡样式，可单条删除，支持加载更多）；
  个人日记先看目录（每页的日期区间与心情圆点），点开进入单页纸质阅读视图，
  顶部「请她写一篇」可主动递邀请；我的日记是关于你的互动评价（目录 + 单篇阅读 +
  素材进度条，可「立即写一篇」/「清空」）
- 快捷操作：设置锚点、快进/回退天数、重置、🌙 查看状态、
  🫖 解除当前情绪

### 多角色（每个角色独立）

每个角色（lanlan）拥有自己完整的一份潮汐状态，**切换角色卡无需重开插件**，
面板自动跟随宿主当前角色--切到谁的卡，就看谁、改谁。

**按角色独立**的：总开关、锚点日期、快进天数、周期参数（自动演算/周期长度/
潮汐期长度/活跃日/活跃窗口）、情绪状态、时光日记、个人日记、我的日记。

**全局共享**的：注入策略（注入模式/间隔/触发关键词）、各阶段提示词与开场白
文案、时区、生活感知、调试模式、屏蔽词表、`[mood]` 情绪系统参数。

两点细节：

- `plugin.toml` 里 `[tide]` 的周期参数现在是**新角色的默认值**；面板里
  改周期参数只作用于宿主当前角色，不影响其他人。
- 旧版（≤0.4.0）的单份数据在升级后首次启动会**自动迁移归属当前角色**，
  旧数据保留备份不删除。
- 所有注入与推送都按角色定向送达；消息轮询也会按记录里的角色字段归属到
  对应角色的状态。情绪动作触发的宿主主动搭话暂停是全局引用计数（仅重度
  负面动作计入）：任一角色情绪生效即暂停，全部解除才恢复。

## 快速开始

1. 安装后启动插件，打开面板设置**潮汐首日锚点**（如 `2026-08-01`），
   留空则首启随机落在平稳期的某一天（装完前几天不会立刻是潮汐日，
   每次安装起点也各不相同；锚点落定后固定，重启不重随）
2. 设置里打开总开关，保存
3. 正常聊天即可。她今天是什么状态，会自然地体现在语气里

> 潮汐期长度、活跃日、活跃窗口默认**自动演算**（基于固定黄体期模型：
> 活跃日 ≈ 周期长度 − 14，潮汐期 5 天，活跃窗口 ±3 天），只需填周期长度；
> 关闭「自动演算」开关后可手动调整每一项。

## 设计原则

- **低侵入**：状态注入有变化门控与频控（默认每 3 条消息至多一次），
  内容没变不重复说；read 注入虽会进入对话历史，但节制的频率
  让记忆抽取自然消化而不是污染
- **不打架**：情绪期自动协调宿主主动搭话（暂停/恢复均只动总开关，
  原值回写）；她的手记经对话上下文自然进入长期记忆，自动碎片只记
  宿主不抽的原话与情绪事件且从不主动注入，个人日记完全不进记忆管线——
  三条路与宿主记忆系统互补不冲突
- **零依赖**：纯标准库实现

## 调试模式快速验证指南（测试用）

大部分内部机制自然触发很慢（兜底等 2 小时、工具校验等 5 分钟、活动感知要你真离开电脑）。
把 `[tide].debug_mode` 设为 `true`（或调 `update_settings` 入口传 `debug_mode: true`），
会注册一组 `debug_*` 入口（Plugin Manager 入口列表 / 命令面板可调用），把每个机制快进到秒级：

| 想验证什么 | 怎么做 |
|---|---|
| 开关是否真的生效 | 开启总开关的瞬间会立即注入一次（日志出现 `body whisper injected`）；不用等满 3 条消息 |
| 注入内容（阶段感受/情绪行/生活感知行） | `debug_inject` —— 强制注入一次并返回全部注入文本 |
| 情绪动作面板不动/想直接触发 | 对她说"让她冷战/爆发/求安慰"（路由到「触发情绪动作」入口），或调试入口 `debug_set_mood`；面板"情绪状态"会实时显示当前动作 |
| 求安抚兜底自动解除 | `update_settings` 把 `open_action_timeout_minutes` 设为 2，然后 `debug_set_mood(action=seek_harbor, minutes_ago=3)`，几秒内自动解除并开口 |
| 限时情绪到期恢复台词 | `debug_set_mood(action=ebb_tide, duration_minutes=30)` 再 `debug_expire_mood`，面板开着时约 5 秒内听到她主动缓和 |
| 生活感知各分支 | `debug_force_activity(idle_seconds=3600)` 或 `(category=work)` / `(category=gaming)` / `(privacy=private)`，再 `debug_inject` 看返回文本；三个参数全空调一次即清除覆写 |
| 注入频控/计数（interval_n） | 连续调 `debug_simulate_user_message`，看返回的 `message_counter` 与 `injected` |
| 工具重注册韧性 | 重启 main_server 后调 `debug_check_tools`，不用等 5 分钟；返回在位/缺失/是否当场重注册 |
| 个人日记资格与邀请 | `debug_journal` 返回当前资格判定（due/reason/页数）；`debug_journal(force=true)` 立即推一次邀请，观察她是否调 `mood_journal_write` 写日记（面板日记 tab 可见） |
| 时光日记碎片捕获 | `debug_capture_fragment` 立即对最近一轮做碎片提取（绕过水位/间隔门控），返回原话/解析结果/是否落盘；先确认碎片槽位在宿主已配模型 |
| 语气感知全链路 | `debug_emotion_sense` 立即分析最近一轮互动（绕过水位/概率/节流），返回 label/置信度/生效阈值/命中分支；先看宿主情感模型是否配置（未配则功能休眠） |
| 我的日记素材与成文 | `debug_review` 返回素材统计（轮数/语气分布/动作事件/碎片数）与双门槛资格；`debug_review(force=true)` 立即成文一篇（素材不足仍拒绝），面板日记页「我的日记」页签可见；先确认成文槽位在宿主已配模型 |
| 时光页（热力图/徽章/月报/摘要） | `debug_stats(seed=true)` 注入 120 天确定性假数据（真实数据先备份），打开时光页即可验证全部可视化；测完 `debug_stats(restore=true)` 还原真实数据、`debug_stats(clear=true)` 清空。只动 stats 数据，周期/情绪/日记不受影响 |
| 阶段切换/开场白 | 面板快进天数（原有功能）跨入下一阶段 |
| 表情联动 | 用 `debug_set_mood` 触发风暴/委屈，观察她回复语气与 avatar 表情是否同步（静默类动作无回复属已知盲区） |

测试完成后把 `debug_mode` 改回 `false`，调试入口会全部注销。

- **语音会话中注入会迟到**：语音模式下 read 消息要等下一次自然热切换才送达；
  而且语音转录短句也要攒满注入频控（默认 3 条）才触发。
  **验证周期注入请用文字对话**，语音会话建议只感受语气变化。

| 日志行 | 含义 |

| `tone direct chat completion failed: <异常类>: <信息>` / `... returned no usable content: payload head=...` | 直连小模型失败（语气感知/碎片提取/我的日记成文共用通道）：前者请求异常，后者 HTTP 通了但响应不是可用的 OpenAI 形态。1.2.2 审查轮起从 debug 升为 warning——面板提示"详见插件日志"自此可查 |
| `reconcile nudge pushed during ...` | 冷战中检测到你在道歉/哄她，已提醒她该调心情转晴工具了 |
| `re-registered N missing llm tools` | 检测到工具丢失并重注册（正常情况不应反复出现） |
| `plugin store ready after N attempts` | 启动时持久存储延迟通电，插件已把它唤醒（N=1 即一次成功） |
| `PluginStore still disabled after N attempts` | 本次启动持久存储始终没通电：状态按"不可信载入"降级，见下方限制条 |
| `shutdown with untrusted startup load` | 上一次那条的后续：本次关机跳过整体回写，**不会**覆盖你的历史记录 |
| `store not ready: ... not persisted` | 存储未通电时改过状态（开关/锚点/情绪/日记/统计/外观都有此预警）：当场生效但没落盘，重启会回到上次的值 |
| `store became ready after an untrusted load: reloading persisted state` | 本次启动存储没通电（上一条降级），会话中途存储回电：插件在放行任何写入前先把盘上真实状态重新载入，替换内存里的空幻影（1.2.2 起，杜绝"回电后一次操作覆写历史"） |
| `store read failed for <key>: ...` | 读存储失败（数据库锁/IO 抖动）：行为仍按"值不存在"降级，但留痕可查——过去读失败静默，表现为"数据突然全空"且零线索 |
| `persist ... failed: ...` | 写存储真失败（磁盘满/数据库锁等）：对应的面板操作会同时向你报错（1.2.2 起不再"显示成功但没写进去"），盘上保持原样；外观/图库的读写自审查轮起同样经此统一出口留痕 |
| `delete ... failed: ...` | 删除存储条目真失败（1.2.2 审查轮起统一留痕）：清除角色/删图等入口会同时向你报错 |
| `pause host proactive aborted: watermark persist failed` | 情绪动作要暂停宿主主动搭话时，暂停水位没存住 → 本次放弃暂停（总开关原封未动），约 10 秒后自动重试；避免"开关关了但恢复凭据丢了"的卡死（1.2.2 审查轮） |

看不到 `user message observed` 也没 `bus memory read failed` → 消息还没进总线或插件未启用（检查面板总开关）。

## 平台机制与已知限制（读完再用）

- **轮询节奏**：平台不会向插件派发聊天事件，插件每 10 秒轮询一次用户消息总线，
  因此注入与限时动作到期检测最多滞后 10 秒。这不是 bug；watcher 订阅机制只支持
  messages/events/lifecycle 总线，承载用户消息的 memory 总线不可订阅，轮询已是插件侧最优解。
- **重启后开关与记录的保持（1.2.1 起）**：平台的持久存储在建插件实例那一刻可能还
  没"通电"（通电开关来自运行配置，而配置此时尚未就位），未通电时读写一律静默空转、
  不报错——看起来就像"你从没开过模拟"。插件现在会在读状态之前先把存储唤醒，因此
  **开启一次即长期有效，重启后开关、锚点、快进、三本日记与相处统计都会原样回来**。
  万一唤醒失败（日志见 `PluginStore still disabled`），本次会走"不可信载入"降级：
  开关当次显示为关，但**绝不把空状态写回盘**，你的历史记录不受损，重启即恢复。
  1.2.2 起这条防线补成了闭环：若存储是在**会话中途**才回电，插件会在第一次写入
  之前自动把盘上真实状态重新载入替换内存幻影（日志
  `store became ready after an untrusted load`），此后一切读写都作用在真实数据上；
  关机时也会把相处统计与"我的日记"素材一并补刷落盘。
  根治在平台侧（应在插件启动前完成存储通电），已按此口径记录，插件不越界改平台。
- **写失败如实上报（1.2.2 起，审查轮补齐外观/图库）**：开关/锚点/删除/清空/成文
  等操作若遇到**真实的**存储写失败（磁盘满、数据库锁），面板会直接报错而不是假装
  成功——内存里当场生效、盘上保持原样，你可以清理空间后重试。1.2.2 审查轮起，
  **面板外观与壁纸图库**也走同一套统一出口：写失败如实报错、未通电留日志预警，
  不再有"显示已保存、重启后壁纸没了"的旁路。注意区分：只有"启动时存储没通电"
  那一种情形仍是静默降级（当场生效、重启即丢，见上一条），因为那种时候连报错
  通道都被平台堵着，插件只能靠日志与自动重载兜底。
- **主动搭话暂停的恢复凭据（1.2.2 审查轮起）**：她冷战期间插件会临时替你关掉
  宿主"主动搭话"总开关，并在恢复时原样打开。这份"关之前的原值"凭据现在**先写进
  存储、才去翻开关**（写失败则整个暂停放弃、稍后自动重试），消除极端情况下
  （凭据恰好没存住 + 强杀）"总开关被关掉却没人记得恢复"的卡死。注意：**在修复之前
  的旧版本里已经卡死的会话无法事后区分**"是插件弄关的"还是"你自己关的"，若发现
  主动搭话一直不开，请到宿主设置里手动打开一次（此后由本机制接管）。
- **中途通电的自动自愈（1.2.2 审查轮起）**：若某次启动存储没通电（见上），而
  会话中途存储回电了，插件现在**每 10 秒的自检步骤会自动把盘上真实状态重载回来**，
  不再需要你打开一次面板来触发；期间随机生成的周期锚点若属可信会话也会当场落盘
  （强杀重启不再重新随机）。
- **语音会话中的送达延迟**：实时语音聊天期间，平台会把被动（read）类消息暂存，
  等下一次会话自然热切换时才送入——语音正吵得热烈时，身体轻语/情绪指令可能迟到。
  这是平台生命周期机制而非插件失灵；文字聊天不受影响。
- **表情联动**：宿主表情管线分析她回复文本的主导情绪驱动 avatar 表情；插件在情绪动作的
  行为指令里要求主导情绪清晰可辨，让表情能跟上情绪；但静默类动作（冷战/已读不回）期间
  她不回复，表情无输入可分析，属已知盲区。
- **与宿主记忆的分工**：宿主自己会从对话里抽取"你的偏好/习惯"类事实并入它的记忆系统；
  时光日记的自动碎片重点记宿主不记的东西——**原话摘录、情绪事件、过激行为**——
  且从不主动注入对话（只有她自主检索 + 重度情绪期间单条轻语），两者互补不打架；
  个人日记完全不进记忆管线，只给你翻看。
- **多角色**：0.5.0 起已实现 per-lanlan 独立状态（开关/锚点/快进/周期参数/情绪/手记各自独立，
  注入按角色定向；详见上文「多角色」节）。面板自动跟随宿主当前角色，
  查看与修改都作用于正在聊的她。
- **切换角色卡与插件重启**：切换角色等操作会重启宿主插件服务。本插件配置为随宿主自动启动；
  若你在 Plugin Manager 里关掉了它的"自动启动/运行"开关，切角色后插件会静默消失、
  面板报"插件未找到"，需手动重启插件。
- **记录存在哪里**：周期开关/锚点/快进、情绪、三本日记、相处统计都写在
  `应用数据目录/N.E.K.O/plugins/forever_companion/data/store.db`（宿主 PluginStore，
  逐写提交）。插件自身不做第二份备份，也不写进 `plugin.toml`。
- **⚠ 覆盖导入目前会清掉全部记录**：在**安装版**（打包运行的 N.E.K.O）里，上面那个
  数据目录**嵌在插件自己的安装目录内部**（`.../N.E.K.O/plugins/forever_companion/`
  既是源码目录也是数据目录的父级）。实测导入 .neko-plugin 覆盖包会连同数据目录一起
  重建——`store.db` 全新、开关/锚点/三本日记/统计一律归零，需要重新开启与设置。
  因此**升级前不要把"记录会自动保留"当成前提**；有想留住的日记/统计，请先在面板里
  翻看并自行保存内容。（开发用源码树布局下两者是分离的，所以这条差异只在安装版显现。）
  Market 更新走的是同一套替换实现还是另有保留逻辑，待验证；确认后本条会更新。
- **重启不会丢记录（1.2.1 起）**：与上一条不同的另一件事——插件读这些记录的时机在
  1.2.0 及之前有问题，会让开关与锚点"每次重启都像被重置"。1.2.1 已修复：**日常重启
  不再需要重新开启模拟**，锚点/快进/三本日记/统计都会原样回来；万一存储未能按时
  通电，插件会走"不可信载入"降级——当次显示为关闭，但**绝不把空状态写回盘**，
  历史记录不受损，重启即恢复。详见上文「重启后开关与记录的保持」。
- **想彻底清除全部记录**：用插件设置里的「清零相处统计」/「清空时光日记」/
  「清空我的日记」等入口（按角色逐项清除），或直接删除上述 `store.db`。
- **相处统计的保留窗口**：徽章与累计总数（相伴天数/总轮数/冷战与和好等）即时重算、
  永久保留；逐日明细（热力图的底层数据）保留最近 730 天，月报保留最近 24 个月，
  超出窗口淘汰最旧——淘汰后旧日子的热度细节不再可见，但总数与里程碑不受影响。
